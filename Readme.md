A constructive maths project to build theorems formally and visualize them.

It mainly consists in 2 interpretors:
- a HoTT (homotopy type theory) interpretor to check syntax and define axioms and theorems
- a latex interpretor to get theorems from custom latex files and build objects from previously constructed ones

LaTeX files mainly constitute the source code, to be able to read proofs in a classical formal.
Once parsed, those files are fed into a GUI app (streamlit) and transformed into formal derivations to visualize them
